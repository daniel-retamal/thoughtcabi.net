# Code of conduct

Be decent. Talk about the work rather than the person who made it.

Harassment and personal attacks are not welcome here, in issues, in pull requests, or anywhere else the project reaches. Disagreement is fine and often the point.

If someone is making this project worse to be part of, contact me, or use GitHub's own [report abuse](https://github.com/contact/report-abuse) form for anything you would rather not post in public.

Contributions that do not fit this may be edited, locked or removed.
